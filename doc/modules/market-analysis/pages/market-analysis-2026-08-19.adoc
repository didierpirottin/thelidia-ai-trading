== Perspectives à 4–8 semaines

=== Scénario haussier — Probabilité 55 %

*Conditions nécessaires* : NVDA dépasse les attentes le 26 août (rev. > $28,7 Mds + guidance solide) ; le 10yr yield ne dépasse pas 4,80 % ; QQQ tient au-dessus de MA50 ($707) ; minutes FOMC ce soir non hawkish.

*Cibles* : QQQ $745–$760 (nouveau ATH), SPY $790–$800.

*Catalyseurs* : (1) NVDA Q2 FY2027 guidance confirme la dynamique IA — semi-conducteurs rebondissent ; (2) Rachats du Trésor calment la pression sur le 30yr ; (3) Fed signale prudence en septembre malgré les dissenters.

=== Scénario baissier — Probabilité 45 %

*Conditions de déclenchement* : le 10yr yield dépasse 5,00 % (borne psychologique) ; NVDA déçoit sur la guidance malgré un chiffre correct ; minutes FOMC révèlent un ton hawkish surprenant ; NFP août (4 septembre) montre une nouvelle faiblesse.

*Supports critiques* : QQQ $694 (zone congestion / support juillet), QQQ $643 (MA200 — correction −10 % depuis le cours actuel).

*Risques de queue* : (1) Escalade géopolitique — spike VIX rapide sur des marchés complaisants ; (2) 30yr yield dépasse 5,50 % — choc obligataire structurel sur les multiples ; (3) Récession surprise — NFP négatif deux mois consécutifs.
